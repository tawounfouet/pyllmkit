## Release gate

Do not create a Git tag or PyPI release until reviewed and accepted:
1. Green CI on final integrated `main` SHA, including isolated wheel/sdist.
2. All four PRs merged in dependency order.
3. ADR-001 through ADR-006 either approved or decisions reconciled explicitly.
4. Licensing, authorship/metadata, changelog and M1 decision recorded.
5. Release documentation updated to reflect actual evidence, not assumptions.
